# Abdalrahman ElGazzawi · Portfolio

Personal portfolio for senior commercial roles in esports & gaming.
Built with Next.js 14 (App Router) · TypeScript · Tailwind CSS · Supabase · Resend.

## Local dev

```bash
npm install
cp .env.example .env.local   # fill in any keys you need
npm run dev                  # http://localhost:3000
```

## Update your content

All site content lives in `src/content/site.ts` — edit that single file
and push to `main` to redeploy.
